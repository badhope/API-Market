How it works

A note on scoring.

Open methodology

Each API is graded on a handful of signal points — not a benchmark, a heuristic. The score is a rough indicator, not a guarantee; always verify before relying on one.

The current scale starts at a base of 50 and adjusts:

  • AuthNo auth is friendliest (+15); API key (+5); OAuth (±0); custom (−5).
  • HTTPSEncrypted endpoint (+20); plaintext (−15).
  • CORSBrowser-accessible (+10); disabled (−5).
  • descUp to +5 for a real description; empty (−5).

Grades

A90+well-documented, encrypted
B75+mostly complete
C60+usable, sparse
D40+thin metadata
F<40scored but bare
